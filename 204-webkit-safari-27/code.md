# Code samples — Session 204

_No Code tab for this session._ The talk is a feature tour; APIs and markup are
described verbally and shown on slides but no copyable Code tab was provided.

## Spoken APIs / features (named in the transcript)

- **JavaScript:** `String.fromCharCode` (the emoji-truncation compatibility story);
  the **Navigation API**; the **Immersive API** (visionOS 27, "works just like the
  Fullscreen API"); the **Fullscreen API**
- **CSS layout:** **CSS Grid Lanes** (pure-CSS masonry); the `stretch` keyword for
  layout; `flow-tolerance` (Grid Lanes tabbing order)
- **CSS functions:** the `random()` function (named values, global-by-default scoping);
  `min()`, `max()`, `clamp()` — now supported inside the HTML `sizes` attribute
- **CSS features kept current:** Anchor Positioning, View Transitions
- **Customizable Select:** `appearance: base-select`; pseudo-elements `::picker`,
  `::checkmark`, `::picker-icon`
- **HTML:** `img sizes=auto`; the `<model>` element with `environmentmap` and
  `stagemode` attributes; `<source>` for multiple model formats; AR Quick Look wrap
- **SVG:** `fx` / `fy` radial-gradient focal-point attributes (SVG 2 default-value
  disambiguation)
- **Metrics:** Largest Contentful Paint (LCP)
- **Tooling:** Safari Web Inspector "Order Numbers"; Safari Web Extension Packager;
  MapKit JS
