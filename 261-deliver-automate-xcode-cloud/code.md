# Code samples — Session 261

_No Code tab for this session._ This is a demo-driven, UI walkthrough — the entire
session is performed through Xcode's Report navigator, the onboarding assistant, and
the various "Manage…" assistants. There are no Swift snippets and the transcript names
no concrete APIs (the only code-adjacent artifact spoken aloud is a Git remote URL the
presenter pastes into the additional-repositories field).

## UI surfaces / actions named in the talk

- Report navigator → **Cloud** tab → **Get Started…** (onboarding assistant)
- Report navigator → **More** button → **Create Workflow…** (onboard a second product)
- Cloud navigator, secondary-click an app → **Set Up Distribution…**
- Secondary-click an app → **Manage Workflows…** → add **Archive** action (required for TestFlight)
- Secondary-click an app → **Manage Webhooks…** (Name + Payload URL → Add)
- Secondary-click an app → **Manage Repositories…** (primary repo + Additional section → Add Git remote URL)
