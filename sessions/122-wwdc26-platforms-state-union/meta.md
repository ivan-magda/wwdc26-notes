# Session 122 — WWDC26 Platforms State of the Union Recap

- **URL:** https://developer.apple.com/videos/play/wwdc2026/122/
- **Duration:** 5m
- **Speakers:** Apple narration (uncredited; condensed recap of the full Platforms State of the Union)
- **Audio:** English.

## Description

The five-minute recap of the WWDC26 Platforms State of the Union, covering the
three headline tracks: **Intelligence** (Apple Intelligence rebuilt on Google
Gemini-derived Foundation Models, an expanded Foundation Models framework, the new
Core AI framework, App Intents + View Annotations), **Platforms** (Liquid Glass
design, resizable iOS apps, SwiftUI improvements, the Spatial Preview Framework on
Vision Pro), and **Tools** (Xcode 27 daily experience, Xcode Cloud, the Device Hub
that replaces Simulator, and agentic coding with third-party model providers).

## Key topics

- Apple Intelligence "rebuilt from the ground up" — new Apple Foundation Models built with Google, leveraging tech behind the **Gemini** family
- Foundation Models framework gains **image input** and **cloud model** support (bring your own frontier provider); **dynamic profiles** for agents/skills
- **Core AI** — a brand-new framework for running on-device models, built into the OS, tuned for Apple Silicon
- **App Intents** + new **View Annotations API** — make app content/actions available to Siri and let users act on what's on screen by asking
- **Liquid Glass** design: more consistent/personalizable, readability-tuned; uniform tighter corner radius on macOS; sharper app icons; **Icon Composer** refraction effects
- **Resizable iOS apps** on iPad / Mac (iPhone mirroring); resizable iOS Simulator + previews
- **SwiftUI**: drag-to-reorder + swipe actions in any container; nested layouts resize up to 2× faster; async image auto-caching; finer toolbar visibility control
- **Spatial Preview Framework** — streams 3D models from Mac into the space around you on Vision Pro
- **Xcode 27**: 30% smaller (Apple Silicon-only), iCloud settings sync, customizable toolbar, color **themes** (Emerald, Neon Noir, Coral Reef)
- **Xcode Cloud**: easier setup, builds up to 2× faster, Vision Pro + Metal-on-Apple-Silicon support
- **Device Hub** replaces Simulator — virtual + physical devices in one place, pinch-to-zoom, live resizing, hardware control from the Mac
- **Agentic coding**: agents from **Anthropic, OpenAI, and Google**; conversations behave like files; plan-first ("you stay the architect"); agents run tests, use playgrounds, customize previews, and drive the running app
- Built-in **specialists** (SwiftUI, accessibility, sizing, testing, performance); extensible via **plugins** (skills, MCP tools, agents over the **agent-client protocol**); Figma + GitHub ship plugins
