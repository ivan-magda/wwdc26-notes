# Code samples — Session 205

_No Code tab for this session._ It's a product/process walkthrough of new App Store
placements and the Asset Library, with no inline Swift.

## Spoken APIs

- **App Store Connect API** — automate uploading and submitting creative assets to the Asset Library (the same flows otherwise done by hand in App Store Connect).
- **Apple Ads Platform API** — automate ad setup flows on the Today tab and Search Results; ships with **open-source client libraries for Swift and more**.
