## Spoken APIs / commands / shortcuts

- **`/plan`** — slash command in the coding-agent editor that invokes the plan tool; scopes work and gathers context (spawning parallel sub-agents) before making any code changes.
- **CMD+Shift+O** — Quick Open; opens files and also jumps to a function or other piece of code by name (used in the demo to locate `paperPhysics`).
- **Top Functions** — Instruments button/view that ranks the most expensive code paths over a selected time range.
- **Generate Translations** — button in the String Catalog (per selected language) that runs the agent in the background to translate UI strings.
- **Generate Recommendations…** — Organizer action that runs a coding agent over diagnostic data to suggest fixes for issues like hangs.
- **String Catalog** — created and populated by the agent during localization; `+` button (bottom-left) adds a language.
- **New project starting points** (File > New): App (SwiftUI), macOS Command Line Tool, Swift package, Playground (standalone `.swift` file with the Playground macro).
- **Device Hub** — window for running/inspecting apps on simulators and physical devices; Inspector exposes accessibility settings (increased contrast, Dynamic Type size, dark appearance) and iPhone Mirroring resize testing (macOS 27).

> Note: `paperPhysics` is a function in the demo's "Paper Airplanes" sample app, not a
> public Apple API.
